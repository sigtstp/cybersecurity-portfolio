## Structure

Each challenge directory typically contains:

- `challenge.zip` - Original challenge description and assets.
- `readme.md` - Challenge-specific overview and link to the full write-up (`write-up.md` when present).

Write-ups are intended as portfolio pieces and study notes, focusing on:

- Enumeration and architecture analysis
- Vulnerability discovery and root cause analysis
- Exploitation steps and payloads
- Mitigations and takeaways
